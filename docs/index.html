01 Why AgentRE

Software does not ship as source code. It ships as evidence.

Most AI coding benchmarks begin with readable code and a clear task. Security teams often begin with neither. They get a compiled program, limited context, and one question: what does this actually do?

AgentRE makes that uncertainty measurable. It tests the difference between analysis that sounds right and findings an organization can trust.

01 / See

Start with the software that actually runs

Agents receive compiled binaries—not source, descriptive filenames, internet access, or privileged clues.

Real-world input
02 / Reason

Turn opaque machine code into a defensible explanation

The task is to recover behaviors, configurations, infrastructure, API chains, and execution details through tool use.

Agentic capability
03 / Trust

Know the difference between evidence and confidence

Correct findings earn credit. Unsupported claims are penalized. Every answer is checked against fixed expert ground truth.

Deployment readiness

02 How it works

An unknown binary goes in. Auditable evidence comes out.

AgentRE turns a difficult, open-ended investigation into a repeatable evaluation. Every agent gets the same constrained environment; every claim meets the same fixed ground truth.

  1. 01

    Present unfamiliar software

    The agent sees a source-free, anonymized binary in an isolated workspace with ordinary static-analysis tools.

  2. 02

    Observe the investigation

    AgentRE records the tools, evidence, time, coverage, failures, and final structured claims—not just an answer.

  3. 03

    Score what can be proved

    Fixed expert ground truth rewards correct technical detail and penalizes unsupported claims. The same answer always receives the same score.

03 Benchmark evolution

Three versions. One increasingly demanding question.

Each release sharpened the measurement: from establishing a source-free baseline, to exposing calibration, to testing exact reconstruction across paired Windows binaries.

V3August 2026
Current · Windows PE

What survives when symbols disappear?

From recognition to reconstruction

Ten Windows programs were evaluated in both unstripped and stripped form across six models: 120 total episode slots.

Main score0–1
Kimi.676
Claude.615
GPT.586

Across 46 valid pairs, stripping reduced the mean score by 6.47% relative.

The finding

Agents recovered substantial behavior after symbol removal. Exact execution chains, configuration, and the final synthetic-worm endpoint remained the boundary.

04 What the evidence says today

Recognition is arriving before reconstruction.

Frontier agents can often identify what family of behavior they are looking at. The harder—and more operationally valuable—step is recovering the exact chain, key, value, or endpoint.
